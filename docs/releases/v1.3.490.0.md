# BetterLyrics v1.3.490.0

## 新增

- 接入 IKUN 播客逐字稿 v2 协议，支持增量更新、断线恢复、说话人标签与逐字高亮。
- 支持 IKUN 博客正文协议，可在逐字稿与正文之间识别正确的长内容来源。
- 新增长歌词、播客逐字稿和博客正文的分页分享，可导出当前页、全部页面或指定范围。
- 批量分享支持进度显示、取消、失败页重试和稳定快照。

## 优化

- 保持长双语歌词分页配对，避免翻译行与原文跨页错位。
- IKUN 播客会话复用现有歌词、桌面歌词和花再音响显示链路。
- 补充中英文及繁体中文界面文案和使用说明。

## 修复

- 修复歌词偏移调整后播放位置不同步的问题。
- 提升未打包环境的启动兼容性。
- 加固长内容批量分享中的分页和失败恢复逻辑。

## 验证

- BetterLyrics.Core Release 测试通过。
- WinUI 3 Release x64 构建通过。
- 三语资源文件 XML 校验通过且无重复键。
