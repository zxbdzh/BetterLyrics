# 播客转写状态与控制设计

## 目标

让用户在 BetterLyrics 播放页面直接确认当前播客是否正在转写、所用模型是否可用、转写处于哪个阶段，并能手动开始、重试或刷新转写。普通歌曲不显示该入口。

该功能由 IKUN 提供真实状态与本机控制能力，BetterLyrics 只负责展示和发起用户明确请求，不通过歌词是否为空来猜测转写状态。

## 用户界面

BetterLyrics 播放页面增加一个仅在当前媒体类型为 `podcast` 时可见的转写状态按钮。按钮使用简短状态文字：

- 未转写
- 排队中
- 下载模型
- 转写中
- 已完成
- 失败

点击按钮打开明细面板，展示：

- 当前播客标题与内容 ID
- 字幕来源：发布者逐字稿、本地 ASR 或 AI
- 字幕状态、修订号、是否为部分结果、当前字幕行数
- ASR 模型：`base`、`small` 或 `medium`
- 模型状态：未安装、检查中、下载中、已就绪或错误
- 当前阶段：等待、下载音频、准备模型、转换音频、识别、保存、完成或失败
- 可用时展示阶段进度与最近一次错误

面板提供以下操作：

- 尚未转写时显示“开始转写”
- 失败时显示“重试转写”
- ASR 已完成时显示“重新转写”，执行前二次确认
- 使用发布者逐字稿时不运行本地 ASR，只显示“刷新状态”
- 所有状态均可“刷新状态”

按钮执行后立即进入等待状态，并以 IKUN 返回的真实状态为准。操作失败时保留原状态并显示明确错误。

## IKUN 状态模型

IKUN 为当前激活播客维护一个转写运行状态，至少包含：

- `contentId`
- `transcriptState`
- `transcriptSource`
- `revision`
- `isPartial`
- `model`
- `modelState`
- `stage`
- `progress`，范围为 0 到 1；无法计算时为空
- `error`
- `updatedAt`

模型下载使用响应体长度计算进度；服务器未提供长度时只报告“下载中”。Whisper 本身无法稳定提供整段百分比时，阶段显示“识别中”，不伪造百分比。

状态变化通过现有 `/subscribe-player-status` SSE 发送，新增字段 `transcription`。现有 `transcript` descriptor 保持兼容，避免破坏旧版 BetterLyrics。

## 本机接口

IKUN Open API 增加仅允许 loopback 请求的接口：

- `GET /transcription-status?contentId=...`：返回当前内容的真实转写状态。
- `POST /transcription-control`：请求体包含 `contentId` 与 `action`；`action` 为 `start`、`retry` 或 `restart`。

约束：

- 内容 ID 必须与当前激活播客一致。
- `start` 不覆盖有效的已完成字幕。
- `retry` 仅重试失败或不可用任务。
- `restart` 只适用于当前来源为 ASR 的已完成内容，清除其 ASR 结果后重新生成。
- 同一内容同时只运行一个任务；重复请求返回现有任务状态。
- 接口继续限制为本机访问，不增加外网控制面。

## BetterLyrics 状态接入

BetterLyrics 新增独立的转写状态模型，由 `GSMTCService` 持有并通过 `IGSMTCService` 暴露给播放页面。职责分离如下：

- SSE 处理器只解析并更新状态模型。
- `PodcastTranscriptBridge` 继续只负责下载增量字幕并转换为 `LyricsData`。
- 新的本机客户端负责查询状态与发送控制命令。
- 播放页面只绑定公开状态和命令，不直接访问 HTTP。

切换到普通歌曲、非 IKUN 来源或另一个播客时，立即清除旧状态，防止上一期播客的模型状态或错误残留。

## 错误处理

- IKUN 未连接：显示“无法连接 IKUN”，保留刷新按钮。
- IKUN 版本不支持新接口：显示“IKUN 不支持转写明细”，歌词读取仍按旧协议工作。
- 模型下载失败：显示模型错误及可安全展示的错误摘要。
- Whisper、FFmpeg 或 Vulkan 失败：显示失败阶段；IKUN 已有 Vulkan 回退行为继续保留。
- 状态查询超时不会清空已经加载的字幕。
- 错误信息不得包含访问令牌、完整请求头或用户私有路径。

## 测试与验收

IKUN 自动化测试覆盖：

- 模型缺失、下载中、校验完成和下载失败的状态转换。
- 音频下载、转换、识别、保存、完成和失败阶段。
- `start`、`retry`、`restart` 的状态约束与任务去重。
- 非 loopback 请求被拒绝。
- SSE 在状态变化时发布 `transcription`。

BetterLyrics 自动化或最小状态机测试覆盖：

- 播客初次连接即收到状态，不丢失首条 SSE。
- 模型与任务状态正确映射为按钮文字和可用操作。
- 切换媒体后清除旧状态。
- 控制接口失败时显示错误且不破坏现有字幕。

人工验收场景：

1. 播放无发布者逐字稿的中文、英文和中英混合播客。
2. BetterLyrics 显示模型名称和准备状态。
3. 点击“开始转写”后能观察阶段变化。
4. 转写完成后逐字字幕正常显示，状态为“已完成”。
5. 制造模型或 Whisper 失败后能看到具体阶段和错误，并可重试。
6. 普通歌曲不显示转写入口。

## 非目标

- 不在 BetterLyrics 中下载或运行 ASR 模型。
- 不修改第三方播客 API。
- 不提供远程网络上的转写控制。
- 不伪造 Whisper 无法可靠提供的识别百分比。
